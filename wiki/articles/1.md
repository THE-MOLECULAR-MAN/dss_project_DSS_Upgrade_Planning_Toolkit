# DSS v12.3.2 upgrade planning

<img src="/static/dataiku/images/dss-logo-about.png" width="70" style="float: right; margin-right: 30px" />

This project is intended to be an initial but not complete guide for Dataiku customers looking to upgrade from DSS v12 to v14 or later. This project is a volunteer, best-effort and is not officially supported by Dataiku.

# Prerequisties:
* Dataiku DSS version 12.3.2 or later
* The appropriate version of the [Datasets about Dataiku Instance plugin](https://github.com/THE-MOLECULAR-MAN/dss-plugin-xzibit). Please note that DSS v12 is not compatible with the latest version of this plugin, so make sure you get the correct version.

# Find out what has changed between versions:
[Dataiku's release notes](https://doc.dataiku.com/dss/latest/release_notes/) include Migration Paths information and change notes. Pay attention closely to the [Limitations](https://doc.dataiku.com/dss/latest/release_notes/14.html#releases-notes-14-limitations) section and take notes.

# Most common things you’ll need to account for during upgrade

Since Dataiku acts as an orchestration layer on top of other technologies, we can only support software that the original authors are still supporting. For example, The Python Foundation ended support for Python 3.6 in  **2021** .

Here's a short list of the most common things that need to be accounted for during migrations:
 - Linux virtual machine’s operating system version changed for DSS Nodes
 - Some R and Python versions are deprecated
 - Some DSS Plugins are deprecated
 - Container base image changes
 - Connection types deprecated
 - Third party model types/versions change
