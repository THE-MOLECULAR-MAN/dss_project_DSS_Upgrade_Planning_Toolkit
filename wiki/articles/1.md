# DSS v12.3.2 upgrade planning

<img src="/static/dataiku/images/dss-logo-about.png" width="70" style="float: right; margin-right: 30px" />

This project is intended to be an initial but not complete guide for Dataiku customers looking to upgrade from DSS v12 to v14 or later.

Learn more about 


https://www.youtube.com/playlist?list=PLSOeMC9bqsYuj7-JM0_iuWj-p8nU9UICX

Reading release notes to see what will change.
https://doc.dataiku.com/dss/latest/release_notes/

Read migration paths to check if automatic upgrade is supported - most are. Read the Limitations section and take notes.
https://doc.dataiku.com/dss/latest/release_notes/14.html#releases-notes-14-limitations

Since Dataiku acts as an orchestration layer on top of other technologies, we can only support software that the original authors are still supporting. For example, The Python Foundation ended support for Python 3.6 in  **2021** .
