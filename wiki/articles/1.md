# DSS v12.3.2 upgrade planning

This project is intended to be an initial but not complete guide for Dataiku customers looking to upgrade from DSS v12 to v14 or later. This project is a volunteer, best-effort and is not officially supported by Dataiku. This project is designed for Dataiku administrators who have mild to moderate experience with DSS, but are not coders. This project is not for end users (Designers). 

This project uses the [Datasets about Dataiku Instance plugin](https://github.com/THE-MOLECULAR-MAN/dss-plugin-xzibit) to gather a large amount of information about this DSS instance to help:

# Find out what has changed between versions:
[Dataiku's release notes](https://doc.dataiku.com/dss/latest/release_notes/) include Migration Paths information and change notes. Pay attention closely to the [Limitations](https://doc.dataiku.com/dss/latest/release_notes/14.html#releases-notes-14-limitations) section and take notes.

# Common things you’ll need to account for during upgrade
Since Dataiku acts as an orchestration layer on top of other technologies, we can only support software that the original authors are still supporting. For example, the Python Foundation ended support for Python 3.6 in  **2021** .

Here's a short list of the most common things that need to be accounted for during migrations:
 - Linux virtual machine’s operating system version changed for DSS Nodes
 - Some R and Python versions are deprecated
 - Some DSS Plugins are deprecated
 - Container base image changes
 - Connection types deprecated
 - Third party model types/versions change


# Set up
1) Install the appropriate version of the [Datasets about Dataiku Instance plugin](https://github.com/THE-MOLECULAR-MAN/dss-plugin-xzibit). Please note that DSS v12 is not compatible with the latest version of this plugin, so make sure you get the correct version.
2) On the flow page, click on Flow actions in the bottom right, then Build All. Select Force-rebuild all dependencies and check the Update output schemas, then click Build.
