## Setup & Execution

### 1. Install the Plugin
This project relies on the **[Datasets about Dataiku Instance plugin](https://github.com/THE-MOLECULAR-MAN/dss-plugin-xzibit)**.

1. Download and install the plugin on your instance.
2. **Critical Version Check:** If you are currently on DSS v12, ensure you download a version of the plugin compatible with v12 (the latest version may require v13+). Check the GitHub tags/releases if necessary.

### 2. Build the Inventory
Once the plugin is installed, you must populate the data:

1. Go to the **Flow** of this project.
2. Click **Flow Actions** (bottom right) -> **Build all**.
3. Select **Force-rebuild all dependencies**.
4. Check **Update output schemas**.
5. Click **Build**.

> **Note:** Depending on the number of projects in your instance, this build process may take **several hours**.
